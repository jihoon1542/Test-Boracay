# 🏝️ 보라카이 여행앱

2026년 12월 16일 ~ 20일, 보라카이 4박 5일 여행을 위해 직접 만든 여행 앱.
아이폰 홈 화면에 추가해서 일반 앱처럼 쓰는 웹앱(PWA)이에요. 설치나 앱스토어 없이 링크 하나로 열려요.

- 테스트 버전: https://jihoon1542.github.io/Test-Boracay/

---

## 주요 기능

### 🗺️ 지도 (첫 화면)
- Mapbox 지도 위에서 바로 확대·이동하고, 가게나 장소를 누르면 Google 장소 정보(사진·리뷰·영업시간)가 떠요
- 화면 위쪽에 여행 진행도 표시: 4박 5일 동안 해가 뜨고 지다가 달이 되는 한 줄 여정 바
- 아래 시트를 끌어올리면 검색, 오늘 일정, 즐겨찾기, 맛집, 카페, 해변을 골라 볼 수 있어요
- 즐겨찾기는 하트 핀으로 표시되고, 확대하면 가게 이름이 보여요
- 길게 누르면 그 자리에 장소 추가, 내 위치 보기, 도보 길안내

### 📋 일정
- 날짜별 일정, 완료 체크, 장소와 연결된 일정은 지도·길안내로 바로 이동
- 일몰 시간과 선셋 알람(일몰 몇 분 전에 알림)

### 🎫 예약
- 항공권 / 숙소 / 투어·액티비티로 나눠서 관리
- 예약 하나에 세부 일정을 여러 개 넣을 수 있어요
  - 예: 투어사 패키지 하나에 픽업 · 선셋 투어 · 호핑투어 · 샌딩
  - 예: 항공권 왕복 하나에 가는 편 · 오는 편
  - 예: 숙소 하나에 체크인 · 체크아웃
- 예약번호, 바우처 캡처·PDF, 메일 내용을 예약 하나에 같이 보관
- 다음에 다가오는 일정에 '다음' 표시

### ➕ 더보기
- **장소 · 맛집**: 저장한 장소와 메뉴 메모
- **체크리스트**: 공통 준비물과 각자 짐
- **경비 · 정산**: 페소(₱)로 입력하면 그날 환율로 원화 환산, 둘이 나눌 금액 자동 계산
- **날씨 · 일몰**: 날씨 예보, 일몰 시간, 선셋 알람 설정, 캘린더(.ics) 내보내기
- **여행 기록**: 사진과 짧은 기록
- 여행 설정, 백업·복원, 일정 공유

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 뼈대 |
| `app.js` | 앱의 모든 기능 (화면, 지도, 저장, 알람 등) |
| `app.css` | 디자인 |
| `data.js` | 해변 모양 좌표, 장소 위치 보정값 |
| `sw.js` | 오프라인에서도 앱이 열리게 하는 서비스 워커 |
| `manifest.webmanifest` | 홈 화면 앱 이름·아이콘 설정 |
| `icons/` | 앱 아이콘 |

빌드 과정 없이 파일 그대로 GitHub Pages에 올리면 작동해요.

## 사용하는 외부 서비스

| 서비스 | 용도 | 비용 |
|---|---|---|
| Mapbox GL JS | 지도, 도보 길안내 | 무료 범위 안에서 사용 |
| Google Maps · Places UI Kit | 장소 정보(사진·리뷰·영업시간), 장소 검색 | 매달 무료 크레딧 범위 안에서 사용 |
| Open-Meteo | 날씨 예보, 도시 좌표 | 무료, 키 없음 |
| open.er-api.com | 환율 (원 ↔ 페소) | 무료, 키 없음 |

### API 키
- 키는 `app.js` 맨 위에 있어요 (`MAPBOX_TOKEN`, `MAPBOX_STYLE`, `GOOGLE_KEY`)
- Google 키는 Cloud Console에서 **웹사이트 제한**을 `https://jihoon1542.github.io/*`로 걸어 둬서, 다른 사이트에서는 쓸 수 없어요
- Google 키의 API 제한에 아래 3개가 켜져 있어야 해요
  - Maps JavaScript API
  - Places API (New)
  - Places UI Kit
- GitHub에 올릴 때 Mapbox 토큰을 '비밀 정보'로 경고할 수 있는데, 공개용(`pk.`) 토큰이라 **"It's a false positive"**를 고르면 돼요

## 업데이트하는 방법

1. 바뀐 파일을 GitHub 저장소에 업로드 (Add file → Upload files → 같은 이름으로 덮어쓰기)
2. 1~2분 뒤 GitHub Pages에 반영
3. 폰에서 앱을 완전히 닫았다가 다시 열면 새 버전으로 바뀌어요

> 코드를 고칠 때는 `sw.js`의 `VERSION` 숫자를 하나 올려야 폰에 남아 있는 옛 버전이 확실히 바뀌어요.

## 데이터 저장

- 일정·예약·경비 같은 데이터는 **각자 폰의 브라우저 안에** 저장돼요 (서버 없음)
- 사진과 PDF는 폰 안의 별도 저장소(IndexedDB)에 들어가요
- 다른 폰과 자동으로 맞춰지지는 않아요. 옮기거나 맞출 때는 **더보기 → 함께하기·백업**에서 백업 파일을 내보내고 가져오세요
- Safari 방문 기록을 지우면 데이터도 지워질 수 있으니, 출발 전에 백업 한 번 해 두기

### 테스트 버전과 실사용 버전
- 두 버전은 같은 주소(`jihoon1542.github.io`) 아래에 있지만 저장 공간을 따로 써요
  - 실사용: `boracay-app-v1`
  - 테스트: `boracay-test-v1`
- 테스트 버전을 처음 열면 실사용 버전 데이터를 한 번 복사해 와요. 그 뒤로 테스트에서 바꾼 건 실사용 버전에 영향이 없어요
- 테스트 버전에서 충분히 써 보고 나서 실사용 버전에 합쳐요

## 아이폰에 설치하기

1. Safari로 앱 주소 열기
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 열기 (주소창 없이 전체 화면으로 열려요)
4. 처음 열 때 위치 권한을 허용하면 내 위치와 길안내를 쓸 수 있어요

## 참고

- 지도 왼쪽 아래 Mapbox 로고와 출처 표시는 Mapbox 이용 약관상 지우면 안 돼요
- Google 장소 정보(위치 등)는 약관에 따라 30일 넘게 저장하지 않아요. 앱이 25일마다 새로 받아요
- D-day 칩을 빠르게 5번 누르면 화면 크기 정보가 나와요 (화면 잘림 문제를 확인할 때 쓰는 기능)
